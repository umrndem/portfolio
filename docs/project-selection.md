# Project selection recommendations

## Flagship case studies

1. **ETS Website — conditional first choice.** It shows the broadest professional web implementation surface: public routes, CMS collections, media, forms, admin, and responsive behavior. It proves full-stack product delivery and structured content architecture. Before inclusion, confirm the employment/client relationship, permission to show screenshots, and Umar’s exact responsibilities.

2. **Sentinel — conditional technical flagship.** It is the strongest evidence of domain modelling, authorization, transactional workflow, and security-conscious backend work. Its weakness is confidentiality and the lack of independently verified production outcomes. Present only as a sanitized private-work case study with approved abstractions.

3. **DataPulse — possible data-science flagship after validation.** It aligns directly with the academic context and covers ingestion through dashboard and forecasting. It needs a reproducible safe dataset, forecast evaluation, clearer evidence of access control, and confirmation of deployment before receiving a detailed page.

## Featured projects

- **Snakinesis:** best public interactive demonstration; it adds computer vision and human-computer interaction distinct from web work.
- **RideFlow:** useful public database/domain example if contribution division and live demo status are clarified.

## Supporting work

- **Financial Tick Data Pipeline:** concise systems/concurrency evidence; include as a technical note rather than a large visual case study.
- **DataPulse:** if not promoted to flagship, retain as a featured analytics card with honest limits.

## Academic work

RideFlow and the financial pipeline appear plausible as academic/coursework-related projects, but the exact courses and assessment context are not verified. Ask before labeling them coursework.

## Private or confidential work

Sentinel and ETS may be discussed only with permission and redaction. The Matootoo project should remain private by default; its personal content and source corpus are not portfolio material.

## Exclude

Do not include the Matootoo project as a normal public project. Do not include all seven repositories simply to increase count. Do not show metrics, “live users,” production scale, AI expertise, or business impact until verified.

## Portfolio set recommendation

The strongest distinct set is: ETS or Sentinel (one approved private professional case study), DataPulse, Snakinesis, and one compact systems/database project. This demonstrates web architecture, data work, interaction engineering, and systems breadth without repeating several dashboard/backend projects.
