# Design decision — Working Proof

## Decision

Proceed with **Working Proof**.

## Signature

The site’s memorable device is a **technical range line**. It has five qualitative waypoints:

`systems → data → databases → product → people`

Every selected project activates the span it genuinely covers. The line never presents percentages, proficiency, impact, or other invented quantities.

## Influences transformed

- Editorial sites informed scan rhythm and metadata hierarchy.
- Data publications informed source labels and explanatory diagrams.
- Documentation systems informed progressive depth and linkable sections.
- Idea-led personal sites informed the need for one authored thesis.
- Studio and product sites provided motion polish lessons, including examples to reject when first-frame content was delayed.

No reference layout, proprietary graphic, text, interaction, or code is reproduced.
