# Public assets

Files in this directory are served without authentication. Add only approved,
publication-safe assets.

- `images/profile/` — approved profile photographs.
- `images/projects/` — sanitized project covers and galleries.
- `images/social/` — optional static social previews.
- `documents/` — public downloadable PDFs such as the approved résumé.
- `icons/` — optional standalone public icons. The active favicon currently uses
  the App Router convention at `src/app/icon.svg`.

Use lowercase kebab-case filenames. Never place confidential screenshots,
credentials, internal exports, private source, or unapproved professional
material here.
