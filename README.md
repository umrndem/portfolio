# Muhammad Umar Nadeem — portfolio

This repository contains the evidence base, design research, and initial Next.js implementation for Muhammad Umar Nadeem’s personal portfolio.

## Current phase

The approved discovery input is complete enough to support an initial portfolio foundation. The current build uses the **Working Proof** direction: selected projects are presented through problems, systems, evidence, and explicit claim boundaries.

This is an initial version, not a launch-ready final. A real profile photograph, approved private-work media, contribution splits, résumé, and several human decisions remain open.

## Documentation map

- `portfolio-source-of-truth.md` — canonical human-provided profile and public/private boundaries.
- `docs/github-inventory.md` — complete repository inventory and classifications.
- `docs/developer-profile.md` — evidence-based technical profile, separating fact from inference.
- `docs/skills-evidence-map.md` — skills mapped to concrete repository evidence.
- `docs/project-catalogue.md` — concise factual entries for meaningful projects.
- `docs/project-selection.md` — selective recommendations for future portfolio treatment.
- `docs/experience-timeline.md` — verified and inferred development sequence.
- `docs/portfolio-content-map.md` — possible future content grounded in available evidence.
- `docs/uncertainties-and-questions.md` — only unresolved questions that affect future positioning.
- `questionnaire.md` and `questionnaire.docx` — an easy-to-complete response form based on the unresolved questions.
- `docs/research-log.md` — inspection methods, files reviewed, limitations, and privacy decisions.
- `research/project-notes/` — deeper notes for projects that may deserve later case studies.
- `research/repository-metadata/` — non-sensitive metadata snapshots used during discovery.
- `research/design/` — 125-site design reference index, retained evaluations, patterns, and anti-patterns.
- `docs/design-research-summary.md` — research scope and synthesis.
- `docs/design-directions.md` / `docs/design-decision.md` — three directions and the selected approach.
- `docs/information-architecture.md` / `docs/design-system.md` — page structure and visual system.
- `docs/brand-identity.md` — oxblood rationale, semantic palettes, contrast, and usage rules.
- `docs/content-boundaries.md` — public-safe, qualified, held, and excluded content.
- `docs/implementation-notes.md` / `docs/future-iterations.md` — stack, verification, limitations, and next decisions.
