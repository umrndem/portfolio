# Muhammad Umar Nadeem — portfolio discovery

This repository is the evidence and planning workspace for a future personal portfolio for Muhammad Umar Nadeem, a fourth-year Data Science student at FAST NUCES Islamabad Campus.

## Current phase

This is the discovery phase. It inventories accessible GitHub work, analyzes project evidence, records uncertainty, and recommends a small set of credible future case studies.

The actual portfolio website has intentionally **not** been implemented. No frontend framework, design system, fabricated project data, or marketing copy belongs in this phase.

## Documentation map

- `docs/github-inventory.md` — complete repository inventory and classifications.
- `docs/developer-profile.md` — evidence-based technical profile, separating fact from inference.
- `docs/skills-evidence-map.md` — skills mapped to concrete repository evidence.
- `docs/project-catalogue.md` — concise factual entries for meaningful projects.
- `docs/project-selection.md` — selective recommendations for future portfolio treatment.
- `docs/experience-timeline.md` — verified and inferred development sequence.
- `docs/portfolio-content-map.md` — possible future content grounded in available evidence.
- `docs/uncertainties-and-questions.md` — only unresolved questions that affect future positioning.
- `questionnaire.md` and `questionnaire.docx` — an easy-to-complete response form based on the unresolved questions.
- `docs/research-log.md` — inspection methods, files reviewed, limitations, and privacy decisions.
- `research/project-notes/` — deeper notes for projects that may deserve later case studies.
- `research/repository-metadata/` — non-sensitive metadata snapshots used during discovery.
