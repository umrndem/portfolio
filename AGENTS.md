# AGENTS.md — portfolio discovery repository

## Purpose

This repository prepares a truthful future portfolio through evidence collection and project classification. It is not yet the portfolio website.

## Rules

1. Every portfolio claim must be supported by repository evidence or explicitly marked as user-provided context.
2. Never invent metrics, users, business impact, job titles, technologies, outcomes, dates, or responsibilities.
3. Treat private repositories as confidential by default. Summarize architecture and contribution only at a safe level; never copy private source, customer data, employee data, screenshots, secrets, or internal operational details.
4. Do not modify inspected repositories. Work inside this repository only.
5. Update the discovery documents when new evidence changes a classification or recommendation.
6. Keep generated copy analytical and specific. Reject generic portfolio language unless it is grounded in evidence.
7. Do not describe a project more impressively than its source material supports.
8. Record uncertainty instead of resolving it through assumptions.
9. Begin design and frontend implementation only after the discovery documentation has been reviewed.
10. Consult existing evidence files before rewriting descriptions.
11. Prefer a small set of distinct, well-supported projects over an inflated project list.
12. Do not push this repository remotely without explicit user permission.

## Privacy checklist

Before committing, inspect the diff for credentials, `.env` values, raw private code, private media, customer or employee information, database exports, and copied confidential history. Keep only factual summaries and safe metadata.
